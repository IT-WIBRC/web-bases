Utiliser le JS dans le HTML pour voir le resultat

Il existe 02 manières d'inclure votre script JavaScript dans votre fichier HTML.

1. En utilisant la balise <script> dans le HTML

Vous pouvez inclure votre code JavaScript directement dans votre fichier HTML en utilisant la balise <script>. Voici un exemple :

<!DOCTYPE html>
<html lang="en">
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>Utiliser le JS dans le HTML pour voir le resultat</title>
    </head>
    <body>
        <h1>Utiliser le JS dans le HTML pour voir le resultat</h1>
        <script>
            // Votre code JavaScript ici
            console.log("Hello, World!");
        </script>
    </body>
</html>

Dans cet exemple, le code JavaScript est inclus directement dans la balise <script>. Lorsque vous ouvrez ce fichier HTML dans un navigateur, le message "Hello, World!" sera affiché dans la console du navigateur. Pour ouvrir la console cote navigateur, appuyez sur F12 ou Ctrl+Shift+I

2. En utilisant un fichier JavaScript externe

Vous pouvez également inclure votre code JavaScript dans un fichier séparé et le référencer dans votre fichier HTML. Voici comment faire :

<!DOCTYPE html>
<html lang="en">
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>Utiliser le JS dans le HTML pour voir le resultat</title>
    </head>
    <body>
        <h1>Utiliser le JS dans le HTML pour voir le resultat</h1>
        <script src="script.js"></script>
    </body>
</html>

Dans cet exemple, le code JavaScript est placé dans un fichier séparé nommé script.js. Vous devez créer ce fichier dans le même répertoire que votre fichier HTML et y ajouter votre code JavaScript. Par exemple, le contenu de script.js pourrait être : 

// script.js
console.log("Hello, World!");

Lorsque vous ouvrez ce fichier HTML dans un navigateur, le message "Hello, World!" sera également affiché dans la console du navigateur, tout comme dans le premier exemple.
