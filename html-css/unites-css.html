Encyclopédie des Unités CSS

Comprendre la différence entre l'absolu, le relatif et le viewport.

Absolu

1. Le Pixel (px)

Le pixel est l'unité de base historique. Un pixel correspond à un point sur votre écran (en théorie).

Largeur fixe : 300px

Problème : Si vous zoomez ou changez d'appareil, 300px restent 300px. Ce n'est pas "flexible".

Relatif au Parent

2. Le Pourcentage (%)

Il dépend de la taille de l'élément qui le contient (le parent).

Largeur : 50% de mon parent
Relatif au Texte

3. Le REM (Root EM) et le CH

Le rem est basé sur la taille de police de <html>. C'est l'unité reine de l'accessibilité.

Texte 2.5rem

Le ch calcule la largeur du caractère "0". Très utile pour limiter la largeur des paragraphes.

Cette boîte fait 45 caractères de large (ch). C'est la largeur parfaite pour ne pas fatiguer l'œil lors de la lecture d'un article.
Relatif à l'Écran

4. Viewport Width/Height (vw / vh)

Ces unités ignorent le parent. Elles regardent directement la fenêtre du navigateur (Viewport).

30vw (30% de l'écran)

Note : 100vh est la technique standard pour qu'une section occupe toute la hauteur de l'écran de l'utilisateur.

Papier

5. Le Point (pt)

Unité destinée à l'impression physique. 1pt = 1/72 pouce.

Texte en 14pt (Regardez la différence en faisant CTRL+P pour imprimer).
