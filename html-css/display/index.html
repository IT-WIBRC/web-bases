Maîtriser CSS display

Introduction : En HTML, chaque élément est une boîte. La propriété display décide si cette boîte est "égoïste" (prend toute la ligne) ou "sociable" (accepte des voisins).

1. Le mode "Block" (L'égoïste)

Un élément en block commence toujours sur une nouvelle ligne et s'étire à gauche et à droite autant qu'il peut.

Bloc n°1 (div)
Bloc n°2 (div)

Exemples par défaut : <div>, <h1>, <p>, <section>.

2. Le mode "Inline" (Le sociable limité)

Les éléments inline se suivent comme les mots dans une phrase. Gros piège : Ils ignorent les propriétés width (largeur) et height (hauteur).

Je suis en ligne Moi aussi On ignore la largeur de 1000px du CSS !

Exemples par défaut : <span>, <a>, <strong>.

3. Le mode "Inline-Block" (Le sociable puissant)

C'est comme l'Inline, mais il autorise l'utilisation de width et height. Parfait pour faire des boutons ou des vignettes de produits.

Vignette 1 (200px)
Vignette 2 (200px)

4. Le mode "Flex" (Le chef d'orchestre)

Ici, on ne change pas le display de l'élément lui-même, mais celui de son PARENT. Cela permet d'aligner les enfants très facilement.
