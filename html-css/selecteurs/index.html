2. Sélecteurs d'Attributs (La Précision)

Les sélecteurs d'attributs permettent de styliser sans ajouter de classes partout dans le HTML.

Regardez le haut de cette page. Il n'y a pas d'espace blanc inutile entre le bord du navigateur et le contenu. C'est grâce au * { margin: 0; } qui "reset" le design.
